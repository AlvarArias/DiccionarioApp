DIXIO — PROGRESS LOG
====================
Last updated: 2026-05-20

---

COMPLETED FEATURES
------------------

1. NaturalLanguage — Auto language detection
   - NLLanguageRecognizer in WordSearchViewModel.detectLanguage()
   - Returns true (Swedish) / false (Spanish) / nil (ambiguous → default swe)
   - Files: View Model/WordSearchViewModel.swift

2. Search suggestions with history + UITextChecker
   - Native SwiftUI .searchable — placement: .navigationBarDrawer(displayMode: .always)
   - Suggestions = session history + UserDefaults favorites + UITextChecker system completions
   - Filtered case-insensitively, sorted, capped at 8 results
   - Files: View Model/WordSearchViewModel.swift, Views/Home/WordView.swift

3. Word normalization before API call
   - Search input lowercased before calling fetchPosts(word:dir:)
   - Files: View Model/WordSearchViewModel.swift

4. Lexin API fixes
   - Fixed wrong dir values ("to"/"from" → "swe"/"spa")
   - Fixed JSON malformation bug: API sends \" as \" — preprocessed before JSONDecoder
   - Made Words.result optional ([Result]?) — API omits Result key when no match
   - Added Words.corrections ([String]?) — API returns this instead of Result on no match
   - Files: View Model/WordViewModel.swift

5. Foundation Models — AI example sentences (iOS 26)
   - ExampleSentenceView.swift using on-device Apple Intelligence
   - Uses SystemLanguageModel.default + LanguageModelSession
   - Streams response progressively with streamResponse(to:)
   - Graceful degradation if Apple Intelligence not available
   - Files: Views/Detail/ExampleSentenceView.swift

6. QuizView empty-state guard
   - Shows "Save words first to use flashcards." when CoreData has no words
   - Files: PremiumViews/QuizView.swift

7. TriviaView empty-state guard
   - Requires ≥2 saved words to play; shows message + dismiss button
   - Files: PremiumViews/TriviaView.swift

8. Speech framework — voice search
   - SpeechRecognizer.swift: SFSpeechRecognizer, publishes transcript in real time
   - toggle(locale:) starts/stops recording; stops automatically on isFinal
   - WordView fires performSearch() automatically when speech ends
   - Locale follows selectedLang: sv-SE (Swedish) or es-MX (Spanish)
   - Does NOT work in simulator — requires physical device (AVAudioEngine)
   - Permissions: NSSpeechRecognitionUsageDescription + NSMicrophoneUsageDescription in Info.plist
   - Files: View Model/SpeechRecognizer.swift, Views/Home/WordView.swift

9. ViewModel-per-View refactor (branch: refactorizacion)
   - WordView → WordSearchViewModel (performSearch, suggestions, voiceLocale, detectLanguage, UITextChecker)
   - DetailView → DetailViewModel (saveWord, speak, isSaved, isDuplicate)
   - TriviaView → TriviaViewModel (startGame, checkAnswer, updateRandomIndex, doSomethingAfter30Seconds)
   - QuizView → QuizViewModel (updateRandomIndex, randomIndex)
   - Views now have zero business logic; FetchRequest/animation state stays in views
   - NSManagedObjectContext passed as parameter to ViewModel methods (cannot live in ViewModel)
   - Files: View Model/WordSearchViewModel.swift, DetailViewModel.swift, TriviaViewModel.swift, QuizViewModel.swift

10. ChatGPT/OpenAI removal (partial)
    - Removed @AppStorage("apiKey") and @AppStorage("hasApiKey") from SettingsView
    - Removed commented-out OpenAI TextField from SettingsView
    - PENDING in Xcode: delete OpenAPIViewModel.swift, ChatView.swift, remove ChatGPTSwift package

11. Test suite — 43 unit tests
    - MockURLProtocol: URLProtocol subclass for network mocking, no real API calls
    - URLSession injection in WordViewModel: init(session: URLSession = .shared)
    - API error tests: network error, HTTP 500, HTTP 404, malformed JSON,
      corrections-only, empty results, valid response, dir="swe", dir="spa"
    - Lexin quote bug fix test
    - Fixed existing tests that used wrong dir values ("to"/"from")
    - WordSearchViewModel: performSearch, suggestions, voiceLocale
    - TriviaViewModel: startGame, index bounds/uniqueness, checkAnswer, game-end
    - QuizViewModel: valid index, empty list no-crash
    - DetailViewModel: save new word, duplicate detection (in-memory CoreData)
    - Files: DiccionarioAppTests/DiccionarioAppTests.swift
